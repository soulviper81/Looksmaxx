# Looksmaxx — Appearance Lab

A clean rebuild focused on a mobile-first photo-audit experience.

## Current build
- Mobile-first responsive interface
- Photo upload and direct camera capture
- Desktop drag-and-drop upload
- Rotate, flip, replace and remove controls
- Browser-side brightness, contrast and sharpness analysis
- Native FaceDetector support when available
- Presentation score with practical improvement tips
- Local scan history using browser storage
- No backend required for the current prototype

## Development
The working rebuild is on `rebuild-v1`.

Nothing from this rebuild has been intentionally deployed to Netlify. The existing `looksmaxxdibya` project remains on its previous production deploy.

## Later
A real AI facial-analysis endpoint can be added behind the same frontend without rebuilding the interface.
